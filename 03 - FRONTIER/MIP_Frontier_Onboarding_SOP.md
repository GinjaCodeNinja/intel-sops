# Frontier — Onboarding SOP *(placeholder)*
## AI Discovery Journey · Frontier Stage (Scale-Readiness) · For the AI Expert

**Status:** Internal Working Draft v0.1 — **placeholder.** EOS-style (20/80, point form). Points marked `⟨PENDING → Register §X⟩` await the weekly group — see `NCA_Frontier_Open_Decisions.md`.
**What this covers:** the setup to graduate a client's toolset to **Frontier** — the Scale-Readiness stage (Claude + third-party AI, integration readiness, unattended-AI governance groundwork). Frontier is **engagement-based** and runs **on top of a continuing Outpost base**, and hands bespoke build work to Apex.
**Boundary:** Onboarding gets a client Frontier-ready — tools graduated, integrations mapped, governance stood up. Scoping and delivering the first *build* engagement lives in `NCA_Apex_Onboarding_SOP.md`.
**Stance:** Consult-construct — the client approves, owns, and is accountable for what goes into production.

---

## 1. Purpose & boundary
- Get a Frontier-ready client set up: Outpost base confirmed, integration map in hand, autonomous-agent governance stood up.
- Frontier = **Rail A Stage 6 entry (Extend & Orchestrate — tool arrival)** + **Rail B B5–B6 (inventory platforms, assess integrations)**; MI components Systems Integration, Advanced Agents, AI Operations. Readiness **Level 5**.

## 2. Trigger & entry
- Trigger: an Outpost client hits **Frontier-readiness** (mature Copilot, first agents valued, wants Claude/third-party/integration, has a specific LOB system to connect). ⟨signals → Register §A1 (align to Outpost F3)⟩
- **Confirm the Outpost base continues underneath** — nothing turns off. ⟨→ Register §A3⟩
- Confirm exec sponsor + a technical point of contact on the client side.

## 3. Confirm the foundation is real *(don't skip — highest-stakes work so far)*
- Governance minimum in place; the workspaces/data in scope are **signed off** (Rail B / B3). If not, open/extend the **Foundation Catch-Up Backlog** — Frontier does not build on ungoverned data. *(framework §3, §9.)*
- Copilot maturity confirmed (Frontier assumes Outpost-level fluency + first agents).

## 4. Complete the integration map
- Complete the **Third-Party Platform & Integration Inventory** (B5) and **connection triage** (B6) for the systems in scope. *(reuse `NCA_ThirdParty_Integration_Inventory.md`.)* ⟨who/when → Register §C1⟩
- For each target system: native → vetted vendor MCP → reputable community → custom build; note the consent/approval path. ⟨vetting → Register §C2, §C3⟩

## 5. Set up Claude & third-party AI *(safely)*
- **Claude safe-configuration** (folds into Stage 2 governance) before any real use. ⟨→ Register §E1⟩
- Confirm **Claude / third-party licensing** and seats. ⟨→ Register §E2⟩
- Note support scope for Claude / ChatGPT / xAI and Copilot Studio. ⟨→ Register §E3⟩

## 6. Stand up autonomous-agent governance *(before anything unattended, so Apex has ground to build on)*
- Establish the **heavier gate** and the **AI Operations** basics: an agent/integration **registry**, an **approval workflow**, **monitoring**, **kill switches**, and a **named human owner** per agent. ⟨tooling → Register §D2; owner → §D4⟩
- Confirm the **unattended/"Co-work" path**: sandbox-first → usefulness rubric → heavier gate before real use. *(reuse `NCA_Unattended_AI_Starter_Kit.md` — placeholder.)* ⟨→ Register §D1, §D3⟩

## 7. Ready-for-Apex checklist *(handoff to Apex Onboarding)*
- [ ] Outpost base confirmed and continuing
- [ ] Data/workspaces in scope are signed off (or catch-up backlog opened)
- [ ] Integration inventory + triage complete for the systems in scope
- [ ] Claude/third-party configured safely + licensed
- [ ] Autonomous-agent governance stood up (registry, approval, monitoring, kill switch, owner)
- → Hand off to **`NCA_Apex_Onboarding_SOP.md`** to scope the first build engagement.

## 8. Open decisions index
- Points marked `⟨PENDING⟩` map to `NCA_Frontier_Open_Decisions.md`. As the group decides, update this SOP and drop the flag.

---

*Cross-stage:* Frontier stacks on Outpost (and Pathfinder beneath it) — nothing turns off. A client who "jumped" here still owes the Pathfinder/Outpost foundation via the **Foundation Catch-Up Backlog**; Frontier's §3 enforces it (no building on ungoverned data), regardless of stage entered at.
