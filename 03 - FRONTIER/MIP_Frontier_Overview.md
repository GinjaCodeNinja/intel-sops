## What this stage is
- **Position:** the **Scale-Readiness** stage. Readiness **Level 5+**.
- **Character:** **engagement-based** (scoped per initiative, additive), running **on top of a continuing Outpost base**. Graduates the client's toolset and closes out the last of the foundation work before Apex.
- **Tools:** Copilot **plus Claude and other third-party AI**.
- **Delivery role:** an **AI Expert** (scopes/designs, sets up the tool graduation and the governance groundwork).
- **Goal:** graduate the client from Copilot to Claude + third-party AI, get their third-party platforms inventoried and triaged for integration, and stand up the governance an autonomous system needs — so Apex has solid ground to build on.

## What happens
- **Tool graduation:** Copilot → Claude + other third-party AI (ChatGPT, xAI) — the client's daily toolset expands.
- **Integration readiness:** the **Third-Party Integration Inventory** (B5) + **connection triage** (B6) for platforms in scope.
- **Unattended-AI governance groundwork:** the **heavier gate**, the sandbox-first path, and Claude safe-configuration — stood up here so Apex can build on it, not built here.
- Mostly **Rail B B5–B6** (platform inventory + integration triage) + the Rail A A6 tool-graduation entry.
- **Hands bespoke build/integration work to Apex** — Frontier gets the client *ready*; Apex is where custom agents, integrations, and web apps actually get built.
