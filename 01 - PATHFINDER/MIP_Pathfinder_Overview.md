# Pathfinder · Foundation — Overview
## Northern Copilot Advantage · Stage Overview

**Status:** Internal Working Draft v0.1 — stage name is final; delivery details below still draft.
**Read this first** for Pathfinder, then the Onboarding SOP, Delivery SOP, and Open Decisions.

---

## What this stage is
- **Position:** the **Foundation** stage — the first stage after Kickstart. Readiness **Levels 1 → 3**.
- **Character:** a **governance managed-service**, not a consulting engagement. It **excludes** the AI-Expert monthly session (that's Outpost).
- **Tool:** Copilot.
- **Delivery role:** a **Pathfinder delivery lead** (governance/service).
- **Goal:** get the client's AI house in order — clean, governed data — and activate Copilot for first users.

## What happens
- Pathfinder **starts with the AI Readiness Assessment** — included in sign-up; it's the first step of Pathfinder onboarding.
- The core loop: the **workspace cleanup → Data Owner sign-off → Copilot indexing** cycle (rolling, never "done"), plus Data Owners, an AUP, and incremental Copilot activation for a pilot cohort.
- This is mostly **Rail B (Data & Process Foundation)** work (framework milestones B1–B3) + a light Rail A entry.
