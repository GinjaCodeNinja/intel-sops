# Basecamp — Delivery SOP *(rough draft)*
## For the facilitator

> **ROUGH DRAFT** — grounded in the MIP training-platform README + the existing 90-minute Basecamp agenda; to be fleshed out with **Nick Chubb's delivery documentation**. Points marked ⟨OPEN⟩ need Nick's input or a group decision.

**What this covers:** running the Basecamp workshop, handling cancel/reschedule and follow-ups, and the post-session wrap-up.
**Assumes onboarding is complete** — see the Basecamp Onboarding SOP (session set up in the platform, launch link shared, facilitator prepped). No named owners.

---

## 1. Run the session (~90 min)
- Deliver from the **Player** (PWA, full-screen; **Presenter View** for notes + timer).
- Agenda follows the existing **90-minute Basecamp run-of-show** *(reference the Stage 1 agenda)*. Typical beats:
  - Framing + guardrails (what this is / isn't; Copilot Chat as the safe, approved starting point).
  - How Copilot actually works (mental model; hallucinations vs. confidence).
  - How to write a good prompt (golden rules; before/after).
  - **Hands-on "Now You Try"** exercises (e.g., email drafting/refining) with the simulated-chat and exercise slides.
  - Debrief cards for discussion.
  - Close + the **AI Responsible Use Pledge**.
- ⟨OPEN: confirm the exact lesson order and timings against Nick's delivery notes.⟩

## 2. If they cancel or reschedule
- Reschedule the session; the platform setup (branded plan + link) is reusable, so no rebuild is needed — just confirm the new date and re-share the invite/link. ⟨OPEN: cancellation notice window / policy → group.⟩

## 3. Multiple sessions (large teams)
- Run the booked sessions in sequence; keep the same branded plan. Optionally tailor examples per audience/role group.

## 4. Follow-up session
- If the client wants a follow-up (deeper dive, more role-specific practice, Q&A), book it against the same plan; ⟨OPEN: is a follow-up included or scoped/billed? → group.⟩

## 5. Post-session wrap-up
- Deliver **take-home assets** (prompt starter pack, etc.) via the platform's **File Sharing** (expiry + message).
- Confirm the **AI Responsible Use Pledge** (participant + sponsor package).
- **Leadership readiness-signal debrief** — a short read-out to the sponsor on engagement and next steps.
- **Hand off toward Pathfinder** — tee up the AI Readiness Assessment as the next step.

## 6. Open questions *(for Nick's docs / the group)*
- Exact agenda/timings; cancellation policy; whether follow-ups are included vs. billed; who runs the leadership debrief; how the handoff to the Assessment is triggered.
